Hello All!!
Me and my teammates have created this Fitness Tracker App, a Java based desktop application designed to help users monitor and improve their overall health and fitness.  
It tracks BMI, sleep, water intake, and steps, and even provides AI-powered personalized suggestions using the Gemini API.

## ⚙️ Key Features

- 🧍‍♂️ **User Profile Management** – Add and update age, weight, height, and fitness goals  
- 💧 **Water Intake Tracker** – Log and view daily hydration levels  
- 😴 **Sleep Tracker** – Record sleep duration and patterns  
- 🩺 **BMI Calculator** – Automatically calculates and categorizes BMI  
- 📈 **Weekly Analytics** – Displays activity summaries and progress reports  
- 🤖 **AI Suggestions** – Provides personalized, motivational advice using Gemini API  
- 🗄️ **SQLite Database** – Stores all user data securely

## Technologies Used 
Language - Java
GUI Framework - Java Swing ,AWT
DataBase - SQLite
Gemini flash 2.5 API
